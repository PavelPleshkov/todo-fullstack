# Docs app

Optional Next.js site on **port 3002**. It is **not** started by root `yarn dev`.

From the repo root:

```bash
cd apps/docs && yarn dev:docs
```

Open [http://localhost:3002](http://localhost:3002).

The page is a short local-run guide (ports, env, auth). The full architecture map is **[docs/CODEBASE_MAP.md](../../docs/CODEBASE_MAP.md)** — it is not compiled into this app.
